# Wallify

Wallify is a Flutter-based mobile application designed to provide users with a rich collection of wallpapers. It allows users to browse, view, and manage their favorite wallpapers with a smooth and intuitive user interface.

## Key Features

*   **Extensive Wallpaper Browsing:** Explore a wide variety of wallpapers.
*   **Categorized View:** Easily navigate wallpapers organized by categories.
*   **Favorites Management:** Mark and manage your preferred wallpapers.
*   **Detailed Wallpaper View:** View wallpapers in detail with an interactive image carousel.
*   **Efficient Image Loading:** Utilizes network image caching for a seamless browsing experience.
*   **Connectivity Awareness:** Monitors network status to provide a robust user experience.
*   **Animated UI Elements:** Enhances user interaction with animated text and other UI components.

## Technologies Used

*   **Flutter:** UI toolkit for building natively compiled applications for mobile, web, and desktop from a single codebase.
*   **GetX:** A powerful microframework for state management, dependency injection, and routing.
*   **cached_network_image:** For caching images from the internet.
*   **carousel_slider:** To implement image carousels for detailed views.
*   **salomon_bottom_bar:** Provides an animated and customizable bottom navigation bar.
*   **logger:** A simple, yet flexible and powerful logging package.
*   **fluttertoast:** For showing toast messages.
*   **connectivity_plus:** Checks the device's network connectivity.
*   **animated_text_kit:** A collection of cool and beautiful text animations.
